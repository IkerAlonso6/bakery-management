## Decisiones tomadas
- El controlador global maneja tanto excepciones personalizadas como errores de validación y errores generales.
- Los mensajes de error se estructuran como JSON consistente (`mensaje`, `codigo`, `errores` opcional).
- No se encontraron controllers implementados al momento de crear el handler, por lo que no se agregaron pruebas de integración aún.

## Dependencias generadas
- El resto de los servicios y controllers deben lanzar las excepciones específicas para el manejo correcto por este handler.

## Pendientes / deuda técnica
- Cuando se implementen los controllers, se recomienda probar el flujo completo de excepciones y ajustar mensajes según experiencia real de usuario.
